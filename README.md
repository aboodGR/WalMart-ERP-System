WalMart ERP System

Hi! This is my ERP project that I made with ASP.NET Core and SQL Server. It's an API, so there is no website part, just the backend.

I made it to practice building a real system that a store could use. You can log in, add products and categories, keep track of the stock, make sales, and see some reports.

What it can do
Register and login
Add and edit products and categories
Add or remove stock and see what is running low
Make a sale (the stock goes down by itself)
See reports like total sales and best selling products

What I used
C# and ASP.NET Core
Entity Framework Core
SQL Server
JWT for login
Swagger to test the API

How to run it
Open the project in Visual Studio, put your own database connection in appsettings.json, update the database, and run it. Swagger will open so you can try everything.
